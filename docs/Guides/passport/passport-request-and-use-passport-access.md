Use this guide to request and use Passport access in a policy-compliant way.

## Before You Request

- Confirm the business purpose is legitimate and current.
- Confirm you are requesting the minimum required scope.
- Prepare required context for approval/policy checks.

## Request Workflow

1. Submit request with clear justification.
2. Include required scope details.
3. Wait for policy and approval processing.
4. Access granted resources only within approved limits.

## During Access

- Use access only for approved purpose.
- Do not share access artifacts or credentials.
- Follow handling rules for sensitive data.

## Renewal and Expiration

- Re-request access when needed; avoid standing broad access.
- Expect revalidation for higher-risk use cases.

## Common Rejection Causes

- Missing business context
- Requested scope too broad
- Insufficient attributes for policy evaluation
