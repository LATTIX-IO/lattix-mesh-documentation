Use this guide to create a governed data room with clear boundaries and ownership.

## Prerequisites

- Data room owner identified
- Participant list and purpose approved
- Baseline access rules defined

## Create Workflow

1. Define room purpose and scope
- Document intended collaboration outcome and data boundaries.

2. Configure participant roles
- Assign only required permissions by role.

3. Configure policy boundaries
- Set allowed actions (view/share/export) per role.
- Add time bounds for sensitive collaboration windows.

4. Launch pilot usage
- Start with a limited participant set and validate outcomes.

## Operate Workflow

- Review membership and permissions regularly
- Track critical actions and policy outcomes
- Remove inactive or unnecessary access promptly

## Success Criteria

- Participants can complete approved workflow
- No unapproved broad access appears
- Activity remains traceable for governance review
