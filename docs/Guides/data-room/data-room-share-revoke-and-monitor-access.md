Use this guide to manage access changes in active data rooms safely.

## Share Access Safely

1. Validate need-to-know
- Confirm business need and minimum scope.

2. Apply role-based access
- Use existing role templates where possible.

3. Set boundaries
- Apply time and action limits for sensitive sharing.

## Revoke Access

1. Revoke immediately when no longer needed.
2. Revoke on role change, project completion, or policy conflict.
3. Confirm revocation effectiveness through validation checks.

## Monitor Access

- Review active grants on a regular cadence.
- Watch for unusual activity patterns.
- Escalate anomalies to Security User and Tenant Admin.

## Common Issues

- Orphaned access after user role changes
- Overly broad sharing scope
- Delayed revocation after project closure

## Governance Tip

Treat revocation as a standard lifecycle step, not an exception task.
