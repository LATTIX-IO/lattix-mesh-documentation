Use this guide for regular security review of lineage and control outcomes.

## Review Objectives

- Confirm policy decisions align with expected intent
- Identify anomalous access patterns early
- Build evidence for governance and compliance reviews

## Steps

1. Select review window
- Use a consistent cadence (daily/weekly based on risk).

2. Review high-risk actions first
- Prioritize sensitive resource access, unusual sharing patterns, and exception-path activity.

3. Correlate decisions with policy versions
- Confirm behavior changes are tied to approved policy changes.

4. Capture findings
- Record observations, severity, and required follow-up.

## Escalation Triggers

- Repeated unexpected allows for sensitive data
- Decision behavior inconsistent with approved policy design
- Significant increase in exceptions or overrides

## Output

- Actionable finding list for Tenant Admin
- Evidence package for monthly governance review
