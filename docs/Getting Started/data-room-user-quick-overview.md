Data Room Users collaborate in governed, policy-enforced data spaces.

## What You Can Do

- Participate in approved data rooms
- Access shared assets within authorized scope
- Contribute updates and collaboration actions as permitted

## Typical User Flow

1. Join an authorized data room.
2. Review room rules and access boundaries.
3. Perform allowed collaboration actions.
4. Track and manage ongoing access needs.

## User Responsibilities

- Follow room-level sharing and handling restrictions
- Use data only for approved purposes
- Respect revocation and retention controls
- Escalate policy or access anomalies promptly

## Common Issues

- Permission mismatch between expected and assigned role
- Revoked access after policy updates
- Missing required attributes for room actions

## Security Reminder

Avoid copying governed data into unmanaged channels. Keep collaboration inside approved workflows whenever possible.
