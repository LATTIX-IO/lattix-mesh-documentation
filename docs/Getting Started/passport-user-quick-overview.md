Passport Users request and use controlled access under policy.

## What You Can Do

- Request access through approved Passport flows
- Use granted access for approved business purposes
- View request status and comply with usage constraints

## Typical User Flow

1. Submit a Passport request with clear business justification.
2. Wait for policy/approval outcomes.
3. Use granted access within scope and timeframe.
4. Renew or re-request as required.

## User Responsibilities

- Provide accurate request context
- Follow least-privilege intent
- Respect usage, sharing, and retention boundaries
- Report unexpected access behavior quickly

## Common Issues

- Missing required request context
- Insufficient attributes for policy evaluation
- Expired or out-of-scope access window

## Security Reminder

Never share credentials, session artifacts, or privileged content through chat/email/tickets unless explicitly requested through a secure support process.
