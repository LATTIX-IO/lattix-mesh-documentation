Lattix MVP supports secure, governed workflows for tenant operations, security oversight, and approved data collaboration.

## Core MVP Capabilities

- Configure tenant workspace settings and user role assignments
- Connect supported identity and data sources
- Build, test, and publish ABAC policies
- Review policy decisions and data lineage
- Operate Passport-based controlled access flows
- Create and manage governed Data Room collaboration
- Produce audit-ready activity records through platform views and exports

## What This Means for Your Team

As a customer team, you can:

- Stand up secure access governance without exposing raw infrastructure internals
- Implement least-privilege policy controls for sensitive data handling
- Demonstrate traceability for access and policy outcomes
- Support compliance and audit activities with evidence generated by your usage

## Current MVP Boundaries

For clarity, current SaaS MVP documentation does not cover:

- Self-hosted deployment models
- Public API or SDK integrations for external automation
- Customer-managed platform infrastructure internals

## Recommended Adoption Sequence

1. Complete workspace and user setup
2. Configure ICAM and connector prerequisites
3. Build and validate ABAC policies
4. Enable Passport and Data Room flows for target user groups
5. Establish security and compliance review routines
