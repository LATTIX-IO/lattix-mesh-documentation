This page covers initial tenant setup steps for administrators.

## Step 1: Confirm Tenant Context

- Verify you are operating in the intended tenant workspace.
- Confirm workspace naming conventions and ownership contacts.
- Validate time zone and governance defaults where applicable.

## Step 2: Set Initial Role Assignments

- Assign at least one primary and one backup **Tenant Admin**.
- Assign initial **Security User** reviewers.
- Assign pilot **Passport** and **Data Room** users.

Use least privilege. Start narrow and expand only as needed.

## Step 3: Configure Baseline Access Controls

- Confirm authentication and session controls required by your security policy.
- Review default role scopes and remove unnecessary broad permissions.
- Establish approval expectations for policy and connector changes.

## Step 4: Prepare for ICAM and Connector Setup

- Confirm who can manage ICAM configuration.
- Define change review ownership before connector activation.
- Record approved support contacts for operational issues.

## Setup Completion Checklist

- Tenant Admin and backup assigned
- Security User assigned
- Pilot end users assigned
- Baseline access controls reviewed
- ICAM/connector ownership defined
