Security Users validate that data access and policy enforcement behave as intended.

## What You Own

- Security monitoring and review workflows
- Access decision investigation
- Lineage and policy outcome verification
- Security evidence support for governance/compliance

## Day-1 Priorities

1. Confirm your access scope and review permissions.
2. Review the baseline policy set and known high-risk paths.
3. Validate that lineage and decision records are visible for test activity.
4. Align with Tenant Admin on escalation and incident handling.

## Recurring Security Checks

- Review denied and exceptional access outcomes
- Track policy changes and verify expected impact
- Confirm connectors and identity inputs remain healthy
- Flag suspicious access patterns for admin action

## Investigation Hygiene

- Capture facts first, assumptions second
- Correlate policy version, attributes, and decision outcome
- Escalate with minimal required data only

## Do Not Include in Incident Notes

- Secrets, tokens, private keys
- Unnecessary personal or sensitive data fields
- Internal details unrelated to incident handling
