Use this page for a chronological record of user-visible changes.

## Format

Track entries in reverse chronological order:

- `Added`
- `Changed`
- `Fixed`
- `Deprecated`
- `Removed`

## Template

### YYYY-MM-DD

#### Added
- Item

#### Changed
- Item

#### Fixed
- Item

#### Deprecated
- Item

#### Removed
- Item

## Notes

- Keep entries concise and customer-impact oriented
- Link to detailed guides or release notes when needed
- Do not include sensitive implementation details
