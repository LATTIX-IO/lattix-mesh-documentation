Use this page to announce upcoming removals or behavior changes with enough lead time for customers.

## Deprecation Policy (Recommended)

- Announce early
- Provide migration guidance
- Include effective dates
- Communicate impact by role (Tenant Admin, Security User, Passport User, Data Room User)

## Deprecation Entry Template

### Feature/Behavior Name

- **Status:** Deprecated / Scheduled for Removal
- **Announcement Date:** YYYY-MM-DD
- **Effective Date:** YYYY-MM-DD
- **Who Is Impacted:** (roles/use cases)
- **What Changes:** clear description
- **What You Need to Do:** explicit steps
- **Migration Guide:** link

## Best Practices

- Avoid same-day deprecations for customer-facing workflows
- Keep migration paths simple and tested
- Call out risk of inaction clearly
